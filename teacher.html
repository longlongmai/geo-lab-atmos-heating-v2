① 访问令牌

学生的提交和你的评分，保存在你的 GitHub 私有仓库 里。页面需要一个只能读写这个仓库 Issues 的令牌。令牌只保存在这台电脑的浏览器里，并放进上课链接的 # 后面，不会写进任何仓库。

第一次使用：如何生成令牌（约 1 分钟）
  1. 打开 github.com/settings/personal-access-tokens/new（GitHub → Settings → Developer settings → Fine-grained tokens → Generate new token）
  2. Token name 随意，例如 课堂提交；Expiration 选 7 天或 30 天（到期自动作废）
  3. Repository access 选 Only select repositories，只勾选 geo-lab-submissions
  4. Permissions → Repository permissions → Issues 选 Read and write，其他保持不动
  5. 点 Generate token，复制以 github_pat_ 开头的令牌，粘贴到下面

令牌泄露的最坏情况：有人在这个仓库里乱发评论，影响不到你的其他仓库。课程结束后可以在同一页面删除令牌。
